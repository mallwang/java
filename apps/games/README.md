# Games

Games modernized from old Eclipse projects or JARs, rebuilt as Java 21 Maven projects. Every app folder has `legacy/`
(original material) and `modernized/` (project with README: how to run, development guide, changes).

| App | Description | Modernized version |
|-----|-------------|--------------------|
| [spacewar](spacewar/modernized/README.md) | Side-scrolling shooter "Space Invasion" | 2.0 |
| [volle-lotte](volle-lotte/modernized/README.md) | Dice game with cards for 2-5 players | 2.0 |
| [anno1404-produktionsrechner](anno1404-produktionsrechner/modernized/README.md) | Production calculator for ANNO 1404 | 2.0 |

Migration plan, status table and log: [docs/legacy-modernization.md](../../docs/legacy-modernization.md).
