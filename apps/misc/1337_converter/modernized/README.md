# L337 Converter

Converts text to leetspeak while you type. Choose *simple* (`a -> 4`, `e -> 3`, ...) or *ultimate*
(multi-character substitutions such as `h -> /-/`). The result can be copied to the clipboard.

Modernized from the legacy `1337_Converter_v1.2.jar` (see `../legacy/`), reverse engineered with CFR
(raw output in `../legacy/decompiled/`).

## How to run the application

Requirements: Java 21 or newer and a desktop environment.

```bash
java -jar target/leet-converter-2.0.jar
```

Type in the left box, the result appears on the right. Menu *Style* switches the UI texts to leetspeak;
the button copies the result to the clipboard.

## Development Guide

### Requirements

- JDK 21, Maven 3.9+

### Build, test, package

```bash
mvn test       # conversion tables, no display needed
mvn package    # tests + target/leet-converter-2.0.jar (executable)
```

### Project layout

```
src/main/java/leet/Leet.java       conversion (no Swing)
src/main/java/leet/LeetApp.java    window, live conversion, clipboard, clock
src/test/java/leet/LeetTest.java
```

### Changes compared to v1.2

- Conversion uses lookup maps and a `StringBuilder` (before: ~170 lines of `switch` and quadratic string
  concatenation, `toLowerCase()` on every character).
- The clock runs on a `javax.swing.Timer`; before, an endless loop in `main` with `Thread.sleep`. It now shows
  24 h instead of 12 h.
- Static widget state and local mouse-listener classes replaced by one class with lambdas and a document
  listener; layout managers instead of absolute positions (the window is no longer fixed-size).
- L337-style UI texts are generated by the simple conversion instead of hand-written strings, so a few differ
  slightly from the legacy wording.
- The Eclipse `JarRsrcLoader` wrapper is gone (Maven jar plugin with a normal main class).
